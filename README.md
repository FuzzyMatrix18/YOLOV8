A computer vision application built with **YOLOv8** for real-time object detection, segmentation, and tracking.

---

## 📌 Project Features
- **Real-Time Detection:** Run inference on images, video streams, or webcam feeds.
- **Custom Model Training:** Easily fine-tune pre-trained YOLOv8 models on custom datasets.
- **Multi-Task Support:** Supports Object Detection, Instance Segmentation, Pose Estimation, and Classification.
- **Model Export:** Export trained models to ONNX, TensorRT, CoreML, or TFLite for edge deployment.
